DC LEDGER — armour & asset technique, distilled from source
===========================================================
What this is: eleven tutorials transcribed in full and boiled down to the
technique that actually transfers. Not summaries — the moves, the settings,
the order, and the reasons.

TWO TRACKS, KEPT SEPARATE ON PURPOSE
  zbrush/   the primary track. Sculpt-led, mask-and-extract, layers + morph
            target, IMM hardware, polypaint.
  blender/  the parallel track. Modifier-led, shrinkwrap panels on a smooth
            base, exact parametric operations.

They are NOT merged. They are different ways of thinking and mixing them in
one document makes both mushy. bridge-zbrush-blender.md is the only place
they touch, and it covers the handoff, not a blend.

  pipeline-spine.md     stage ordering for a whole asset (structure, not craft)
  macros-and-tooling.md what to automate, and the engines that do it
  raw/                  all eleven transcripts, verbatim, 501,284 characters

PROVENANCE RULES — how to read this
  Every technique here came out of a transcript in raw/. If a claim is not in
  raw/, it does not belong in this ledger.
  Where a source states a number (a value, a count, a setting), the number is
  reproduced as stated and attributed. Where a number is absent, none is
  invented.
  Timestamps are NOT available. YouTube's caption API refuses this network
  (IpBlocked); the route that worked returns untimed text. So nothing here is
  cited to a timecode — it is organised by technique instead. If you want the
  moment on screen, search raw/ for the phrase.
  The three "pipeline" sources are one author (Stefan Vaskevich: the YouTube
  channel and both learn3d.ai pages). Treat them as one voice, not three
  independent confirmations. Both web pages are sales pages; their per-module
  TOOLS lists are image logos and did not survive text extraction, so the tool
  names they recommend are NOT captured here.
