## Description

In this tutorial series you will be taken through the complete development process to create a stylised game environment for Unity. We will be using Blender for modelling and Substance Painter for texturing, and all you need to get started is basic knowledge of the Blender interface. 

In the first part of this series we will make a plan for the type of environment we wish to create. Then, we will move onto modelling the main environmental elements in 3D. This will be architectural elements such as an arch, bridge and brick wall as well as landscape meshes such as cliffs. These meshes will be ready for texturing which you can learn here:
